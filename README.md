# 3-Stage Pipeline 

A 3-stage pipelined processor RTL design written in Verilog and testbench written in system verilog .

## Pipeline Stages
1. **Fetch**
2. **Decode**
3. **Execute**

## Modules Designed
- PC
- Instruction Memory
- Register File
- Immediate Generator
- ALU
- Control Unit
- Data Memory
- Pipeline Registers

## Simulator
Vivado
